# Child-data review note

Minimum school-linked aliases, class, age group and optional parent-selected caution are used for planning. Shared operational screens use counts; no diagnosis is collected. Kid responses contain only school name, flag and approved action/question codes. Parent/teacher access follows verified school links. Logs/traces must not capture request bodies, tokens, child records or arbitrary school notes.

Before a real India pilot, obtain legal review of DPDP applicability, verifiable parental consent, retention/deletion, school-controller/provider responsibilities, incident notification and children's-data restrictions. This is a review checklist, not a conclusion of compliance. Verify current commencement rules and any applicable educational exceptions with qualified counsel. No exemption is assumed.
